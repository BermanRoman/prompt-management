# Работа с библиотекой управления

Вход — `promt.md`, содержательный аппарат — `management-methodology.md`, порядок выполнения — `workflow.md`.

Модуль текстовой подготовки — `modules/copywriting.md`; канон инфостиля и голоса хранится в отдельном promt-copywriting, а не копируется сюда.

Сохраняй все 28 категорий и их условия применения; стилистическая редактура не меняет управленческий вывод, факты, степень уверенности или полномочия.

Для простой задачи достаточно ведущего; составная работа получает отдельные роли только при полезной самостоятельной части, полная авторская записка — независимого читателя по профилю.

Не создавай вложенные интервью, согласования и повторные циклы вместо уже действующего процесса проекта.

Указания о подготовке текста не разрешают отправку, публикацию и другие внешние действия.

Личные тексты, источники, состояние и отчёты испытаний храни в игнорируемом runs/ либо вне библиотеки.

Перед изменениями проверь Git-статус, после — затронутую передачу и ссылки; перед push нужны отдельное ревью и применимые проверки.

Для инструмента зависимости: `python3 -m unittest discover -s tests -v`; для реального подключения: `python3 scripts/copywriting.py check`.

Не переключай существующий клон зависимости автоматически; сверяй закреплённую ревизию и фактические байты, включая обход локального git replace.

Модели и доступы определяет среда пользователя; этот репозиторий их не меняет.
