# Подключение копирайтинга

Канон — отдельный [promt-copywriting](https://github.com/BermanRoman/promt-copywriting), проверенная ревизия и SHA 13 используемых файлов — в [dependencies.json](../dependencies.json).

Модуль читает исходные карточки и голос, не хранит их сокращённую копию в библиотеке управления.

## Локальная установка

Существующий соседний каталог promt-copywriting используется без переустановки.

Если зависимости нет, создай новый клон и только в нём выбери закреплённую версию:

```sh
git clone --no-checkout https://github.com/BermanRoman/promt-copywriting.git ../promt-copywriting
git -C ../promt-copywriting checkout --detach bb091b6003f836106d09ed2bd5e91a8fb5d961dd
```

Команды выполняются из корня prompt-management; существующий рабочий клон ими не переключай.

Если имеющийся клон другой версии или используемые файлы изменены, сохрани его и подготовь отдельный совместимый клон в новом каталоге, передав его абсолютный путь через --root.

Скрипт не скачивает, не переключает и не исправляет зависимости автоматически.

## Проверка и адресное чтение

```sh
python3 scripts/copywriting.py check
python3 scripts/copywriting.py --root /absolute/path/to/promt-copywriting check
python3 scripts/copywriting.py index methodology-copywriting.md
python3 scripts/copywriting.py extract methodology-copywriting.md --heading '12.1. Полезное действие' --heading '12.2. Контекст читателя'
python3 scripts/copywriting.py extract voice-berman.md
```

По умолчанию путь зависимости определяется относительно библиотеки, независимо от рабочего каталога вызова.

Проверяются точный корень Git, закреплённый HEAD, фактические байты всех 13 файлов, их SHA и соответствие Git-объектам без локальных replace-подмен.

Несвязанные изменения в иных файлах не запрещаются; скрытая правка используемого файла не проходит даже при чистом git status.

index возвращает заголовки, extract — полный файл либо полные выбранные разделы ATX с подразделами, без модельного пересказа.

Заголовок указывается точно, без начальных #; вложенные разделы не обрезаются, строки внутри ограждённых блоков кода не становятся заголовками.

Неизвестный или неоднозначный раздел, неверная ревизия, изменённый файл и недопустимый путь дают ошибку до вывода частичного текста.

В stderr идут SHA источника/выборки и число символов; это учёт прочитанного объёма, а не точные токены модели.

Успех возвращает код 0, ошибка — 2; Python 3 и Git достаточны, модель и API не вызываются.

## Среда с файлами вместо локального Git

Сохрани правила управления и модуль в доступных файлах проекта, приложи нужные исходники копирайтинга из закреплённой версии под различимыми именами.

Ссылки сами по себе не загружают содержание: перед работой должны быть доступны полные нужные карточки, голос и роли проверяющих.

Проверку ревизии/байтов выполняй там, где есть соответствующие инструменты; без неё не называй комплект инструментально сверенным.

Недоступный голос или карточка — ограничение результата, а не разрешение имитировать их по памяти.

## Обновление и проверки

Новая версия зависимости требует обновить манифест после проверки её применимых правил, совместимости и передачи результата; автоматического перехода на свежий main нет.

```sh
python3 -m unittest discover -s tests -v
python3 scripts/copywriting.py check
git diff --check
```

Тесты проверяют инструмент на временных репозиториях; качество текста и независимость читателя проверяются отдельным фактическим прогоном.

Инструмент не управляет редакторскими вердиктами и не заменяет [рабочий цикл](../workflow.md).
