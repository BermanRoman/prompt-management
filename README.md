# Управленческие решения

Мастер-промт разбирает управленческие задачи через операциональный аппарат управления: теорию управления (ДОТУ), разрешение противоречий (ТРИЗ) и приоритеты воздействия как аналитическую линзу.

Он берёт задачу, привязывает каждый вывод к конкретной категории методологии и доводит до рабочего анализа, решения или готового текста.

## Для кого создан этот мастер-промт?

Для руководителей, собственников и всех, кому приходится принимать управленческие решения и хочется разбирать задачу по аппарату, а не по наитию.

## Как это работает?

Промт состоит из двух файлов:

- **promt.md** — тонкий операционный слой: кто он, как работает и как обращается к методичке. Идёт в Instructions проекта.
- **management-methodology.md** — вся методология: 28 категорий в трёх блоках. Идёт в Files проекта как база знаний.

Теория вынесена в методичку намеренно: инструкция остаётся лёгкой, а аппарат можно расширять, не трогая логику промта.

### Методология

Три столпа операционального аппарата:

- **ДОТУ — теория управления** (17 категорий). Векторы целей, состояния и ошибки; полная функция управления; устойчивость по предсказуемости; схемы управления вплоть до предиктора-корректора; структурный и бесструктурный способы; и другие.
- **ТРИЗ — разрешение противоречий** (10 категорий). Идеальность и ИКР; ресурсы; функциональный анализ; типы противоречий и приёмы их разрешения; законы развития систем.
- **Приоритеты управления** (1 категория). Аналитическая линза «на каком уровне находится рычаг» — от мировоззренческого уровня до силового.

Методичка содержит только операциональный аппарат — то, чем делается разбор задачи. Каждая категория оформлена единым блоком: что это / когда включается / как применить.

## Как пользоваться?

1. Создай новый проект в Claude.
2. Открой файл **[promt.md](https://github.com/BermanRoman/prompt-management/blob/main/promt.md)**, скопируй его содержимое кнопкой «Copy».
3. Зайди в настройки проекта и вставь содержимое в поле «Инструкции» проекта.
4. Скачай файл **[management-methodology.md](https://github.com/BermanRoman/prompt-management/blob/main/management-methodology.md)** или загрузи его через коннектор этого репозитория.
5. Напиши в чате проекта сообщение: _«Начинаем работу, согласно заложенной в тебя инструкции и методички в пространстве файлов»_
