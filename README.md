# Управленческие решения

Мастер-промпт помогает разбирать управленческие задачи, готовить решения и писать тексты в инфостиле и голосом Романа Бермана.

Сначала система проверяет содержание через применимые категории управления и фактические источники, затем оформляет результат для читателя.

## Состав

| Файл | Назначение |
|---|---|
| [promt.md](promt.md) | Точка входа: запрос, полномочия, режим работы и результат |
| [management-methodology.md](management-methodology.md) | 28 полных категорий: 17 ДОТУ, 10 ТРИЗ и приоритеты управления как аналитическая линза |
| [workflow.md](workflow.md) | Содержание, проверка, исправление и продолжение работы |
| [modules/copywriting.md](modules/copywriting.md) | Подключение инфостиля, авторского голоса и нужных проверок текста |
| [dependencies.json](dependencies.json) | Проверенная версия и SHA исходников копирайтинга |

Управленческая методичка сохраняет формат «что это / когда включается / как применить»; под задачу читаются полные применимые категории.

Инфостиль и голос берутся из [promt-copywriting](https://github.com/BermanRoman/promt-copywriting), без второй редакции этих правил внутри библиотеки управления.

## Какие результаты можно получить

- Анализ ситуации с фактическими основаниями и границами выводов.
- Решение с доступными ресурсами, действиями и критериями результата.
- Готовое письмо, пост, выступление или авторскую записку.
- Редактуру в разрешённых пределах либо аудит текста без переписывания.

Полная авторская записка проходит отдельного Ваську-читателя; короткое письмо не требует обязательной команды агентов.

Юридические формулировки, точные цитаты и код сохраняют свой формат; голос не меняет факты, обязательства и степень уверенности.

## Начать работу

1. Открой библиотеку в среде с доступом к файлам и прочитай promt.md.
2. Для текстового модуля подготовь зависимость по [памятке](docs/copywriting-setup.md).
3. Передай задачу и имеющиеся материалы; уже известные роль, условия и согласования используются повторно.

В среде с загружаемыми файлами помести promt.md в инструкции, остальные нужные файлы и исходники зависимости — в доступную базу проекта по той же памятке.

Примеры запросов:

«Разбери, почему отдел закрывает план по встречам, а оплаты падают; пока без рекомендаций».

«По этому принятому разбору напиши записку моим голосом; факты и оговорки сохрани».

«Перепиши письмо в инфостиле, не меняя обещанный срок».

Для проверки локального подключения:

```sh
python3 scripts/copywriting.py check
python3 -m unittest discover -s tests -v
```

Модель, приложение и подключения выбирает пользователь; библиотека не требует платного API и не меняет окружение.

Рабочие материалы и отчёты хранятся в приватном runs/ либо вне репозитория.

Подготовка текста не даёт автоматического разрешения отправить или опубликовать его.

Сохранность методологии, тесты и фактическая текстовая проба описаны в [протоколе проверки](docs/verification.md).
