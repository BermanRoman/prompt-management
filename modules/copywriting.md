# Инфостиль и голос Романа Бермана

Модуль оформляет подготовленное содержание по канону [promt-copywriting](https://github.com/BermanRoman/promt-copywriting).

Инфостиль, голос и словари не переписываются здесь; проверенная версия и файлы перечислены в [dependencies.json](../dependencies.json), подключение — в [памятке](../docs/copywriting-setup.md).

## Когда подключать

| Результат | Профиль и чтение |
|---|---|
| Короткая правка, письмо, рабочее сообщение, небольшой пост | simple: нужные карточки инфостиля; голос соразмерно каналу и запросу |
| Полная аналитическая записка или авторская заметка | written: инфостиль, полный письменный голос, отдельный Васька после редактуры и проверки фактов |
| Письменная заметка старого гусара | written плюс применимый письменный регистр и словари; грубая лексика и шутки не обязательны |
| Выступление или голосовое | Нужные карточки инфостиля, голос и восприятие на слух; проектные требования к устной проверке сохраняются |
| Проверить текст без просьбы исправить | audit: находки, исходник не переписывается |
| Договор, точная цитата, код, обязательный служебный формат | Ясность там, где она не меняет точный смысл/формат; разговорный регистр и роль рассказчика не навязываются |

Авторский голос применяется по умолчанию к текстам Романа, если текущая просьба не задаёт другую подачу.

Проверка текста сама по себе не даёт разрешения редактировать его; фактический анализ и аудит редакторского качества различаются по запросу.

Полный выпуск Аналитики сохраняет свой алгоритм, фактчек и авторское утверждение каркаса; здесь эти этапы не запускаются второй раз.

Видео относится к процессу своего проекта: этот модуль не подменяет сценарный Motion-профиль письменным Васькой и не обещает готовый ролик.

## Карта чтения

Пути в этой таблице относятся к проверенному корню зависимости, не к prompt-management.

| Файл | Объём и условие |
|---|---|
| prompt-copywriter.md | Точка входа целиком при первом подключении; режим, порядок редактуры и ограничения |
| workflow.md | Текущий профиль, роли, передача, версии, исправления и готовность; один общий цикл с ведущим этой задачи |
| methodology-copywriting.md | Индекс → полные нужные карточки, включая критерии; 12.1 и 12.2 для полезного действия/читателя, блок 7 и 6.6 для самопроверки |
| voice-berman.md | Целиком для авторского текста: повествование, ритм, ограничения и письменная разметка |
| methodology-listening.md | Для голосового — целиком по голосу, для другого произносимого текста — применимые полные карточки; для записки/ветки только 2.2, 4.1 и 4.2, прямо назначенные voice-berman.md как работающие и на глаз |
| roles/writer.md, roles/editorial.md, roles/fact-checker.md | Только назначаемая роль; ответственность может совмещать ведущий в простой задаче |
| roles/vaska-reader.md | Отдельному читателю полного письменного текста вместе с чистым читательским пакетом |
| references/gusar.md, references/gusar-slovar.md, references/gusar-mat.md | Письменный гусар: регистр и применимые словарные разделы; не весь словарь в каждую задачу |
| references/author-edits-gusar4.md | Только при разборе соответствующего образца и его применимых авторских решений, не как композиция любого текста |

Для деловой переписки выбирай применимые карточки блоков 8–11 и финальный чеклист письма; для объяснения сложного — 12–14, для поста — 15–18 по конкретной задаче.

Прочитанное полностью и остающееся в контексте не загружай повторно без изменения версии; новая роль получает сами нужные правила, а не отметку «уже читали».

## Передача содержания

Ведущий передаёт редактору один пакет, используя существующие brief/content/sources задачи:

- Режим, профиль, канал, адресат, полезное действие и критерий готовности.
- Исходный текст либо проверенное содержание, применённые категории и смысловые связи, которые необходимо сохранить.
- ID фактов/расчётов/выводов с источниками, статусами и степенью уверенности; защищённые числа, цитаты и фрагменты.
- Позиция автора, разрешённые изменения, выбранная композиция/охват и уже данные согласования.
- Пути и SHA входов, корень проверенной зависимости, нужные карточки и границы записи.
- Пройденные проверки с охватом/SHA, конкретные открытые находки и использованные круги.

Редактор не проводит повторное интервью, не меняет решение ради эффектной фразы и не пересчитывает числа по памяти.

Возврат — читательский текст отдельно от краткого отчёта: что изменено, какие утверждения затронуты, фактический SHA, выполненные проверки и оставшиеся блокеры.

## Содержание и голос

Сначала собери целый текст по принятому содержанию, затем редактируй смысл, структуру, предложения и слова, после этого применяй голос отдельным проходом.

Слова «возможно», «по данным», «предположительно» нельзя убрать, когда они передают реальную неопределённость, происхождение или границы вывода.

Первое лицо передаёт авторскую оценку; чужие поездки, наблюдения, опыт и дословные слова не становятся биографией Романа.

Источники, чужие заявления и события произведений сохраняют необходимую атрибуцию; авторская трактовка не превращается в установленный факт.

Голос не разрешает дописывать советы в заказанный анализ, обещать результат, менять обязательства или расширять авторский замысел.

Письменный текст под вёрстку соблюдает правила абзацев, прямой речи и пунктуации из voice-berman.md; ограничения TTS на него не переносятся.

Текущая просьба и применимый процесс проекта → поздняя применимая правка автора → профиль голоса → применимый по каналу слой слуха → инфостиль.

Факты, расчёты, точные цитаты и разрешённый объём работы сохраняются при любом стиле.

## Приёмка

Редакторская и фактическая проверки относятся к окончательной версии и сверяют текст с подготовленным содержанием; наличие управленческой методологии не заменяет проверку источника.

Для written ведущий назначает отдельного Ваську по roles/vaska-reader.md: роль, полный видимый читателю текст, видимые ссылки/подписи и нейтральные условия чтения.

В первом проходе читатель не получает content.md, методички, карту источников, историю, замысел, предыдущие отзывы или ожидаемый пересказ.

При повторе получает полный актуальный текст и только таблицу его блокеров/видимых изменений по правилам роли; общий журнал остаётся ведущему.

Автор или редактор этого текста не считается его независимым читателем; без отдельного контекста проверка остаётся открытой.

Короткая правка принятого текста не запускает полный выпуск заново, но затронутые утверждения и связи проверяются; замена всего текста под видом короткой правки недопустима.

Порядок возврата, лимиты и восстановление — [workflow.md](../workflow.md); готовность текущей версии не означает публикацию или подтверждённый эффект на реальных читателях.
